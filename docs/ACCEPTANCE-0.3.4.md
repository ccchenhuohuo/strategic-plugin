### 金额与价格精度

目标引擎在既有 DECIMAL128 配置上实际执行产品表达式与边界矩阵；库外 Decimal 和整数 HALF_UP 双算核对 12 位中间值、两位金额与价格带，没有修改引擎全局或会话配置迁就实现。

真实业务复算覆盖 4,229 个原子键、45 个站点月及 7 项服务响应，10,540 次精确断言、8,548 次容差检查通过：

- 独立源 DOUBLE 重聚合与冻结事实按既有 ±0.01 金额对账合同核对，行数与件数精确相等。383 处原子金额非零差额的最大绝对值为 0.00000296；独立月直算的 90 个金额比较最大差额为 0.00009765，均在合同预算内。
- 冻结 DECIMAL 后的重分组、换汇、增长、份额及列明的展示字段逐值精确核对；独立源形成的同一目标展示字符串也按零容差核对。没有改为逐行定标以消除 DOUBLE 求和顺序差异。
- 本次业务收据限三窗口均有观察的七个一级类目及列明目标字段，不宣称覆盖新进/退出或未列明的 coverage/caveat 等元数据。月行数由完整原子行数一致推导，不冒称另执行过独立月 COUNT。

### 摘要预算与完整性

- 旧同基线的 27 份写作投影从 1,121,779 字节降至 437,562 字节。
- 207 次冻结真实调用回放生成 63 份写作摘要，共 544,475 字节，最大 13,026 字节；726 份 canonical 表格保持原字节，合法数字集合不变。初次恢复 fixture 后的 689,876 字节失败保留，不改写为一次通过。
- 新季度取数、预算和旧 fixture 减半是不同验收：不能拿新季度的总字节代替同基线压缩结果。伪造 footer 不能扩充数字白名单，相关对抗回归通过。

预算分别针对最终 MCP tool result 和写作摘要：compact catalog 16 KiB、其他工具 64 KiB、每份摘要 32 KiB。超限明确拒绝，不截断冒充完整结果。品牌窗口按每页 512 行、至多 128 页和 120 秒预算执行，异常页或重复键整次拒绝。

### 新三重点季报完整链路

2026Q3 的 164 次真实取数全部成功，生成 52 份摘要，共 656,354 字节，最大 19,877 字节。实际绘制的 47 张图均通过版面门禁；章节及最后生成的执行摘要完成独立语义核查，52 个叙述位的输入、稿件与核查归属一致。

最终 assemble、check、collect 均成功：304 张表、52 个叙述位、652 个受校验数字、47 张图，零阻断、零警告。另行独立核对 828 份原始输入逐字不变，工作副本仅有已登记的配置路径迁移；校验与收录正文一致。

首次图表运行因工作副本引用配置位置不适用而全部跳过，不算出图通过；纠正工作副本的定位后才取得实际绘图结果。一次跨词禁词命中通过定向改稿解决，未放宽产品校验。报告及图表仅临时本地收录，没有新建或共享飞书业务报告。

原摘要写手逐一读取全部章节的轨迹未留存；另由独立核查员实际读取四摘要、各自 exec digest 及全部 48 位章节，确认重点一致，没有从章节引入 exec 未提供的数字或事实。补核没有改动报告或旧验收记录，也不追认原写手的读取轨迹。

### 失败历史与结论边界

首次确认丢失演练在 CAS 前遇到引擎错误、没有实际注入，不列为恢复成功；后续独立观测的新演练完成真实确认丢失验证。首次错误未复现，未宣称其根因已定位。初次金额 checker 对两次独立 DOUBLE 求和附加了不符合原合同的末位零差前提；最终按原合同分层核验，不以修改产品口径或展示容差掩盖差异。

## 未覆盖项与使用边界

- 不恢复 MCP OAuth；仅支持 OAuth 的 ChatGPT / Dot 网页连接器不在接入范围。飞书云文档输出是独立能力，继续保留。

- 本轮真实报告使用 unbound 兼容入口与隔离服务，验证脚本引擎及实际角色执行，不冒称新入口的原生宿主绑定或 Workflow 实机验收。
- 飞书发布与恢复的本地回归不冒称本轮真实云端写入；本轮没有新建或共享飞书业务文档。
- 生产不注入合成冲突、缺价或故障；开发库的成功与历史验收记录均不能替代新生产数据的实测。
