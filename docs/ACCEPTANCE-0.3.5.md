日期：2026-10-20。本文随 0.3.5 分发包冻结，记录发行前已完成的本地回归与生产切换验收；发行后的正式安装、宿主连接和运行中会话重载不预写为已通过。

## 本版变化

- MCP 与插件默认 Bearer 地址迁到 `https://voc.ulanzi.com:28081/strategy/mcp`。原 `/flywheel/mcp` 应用路由和反代移除，旧入口显式拒绝，不重定向，也不转交给其他应用。
- 清理无消费者的辅助函数与导入；共用重复快照、配置发现、生成替换和机械外壳。保留业务 SQL、独立验收口径、发布保护、异常状态和现行兼容入口。
- 发现测试直接使用真实 MCP 工厂和包版本，不再维护另一份注册逻辑或过时的固定版本。
- 不改变 14 个工具的查询合同、算术、业务口径、数据代次或 Bearer 认证强度；不恢复 OAuth。

代码部署、数据发布和插件安装是独立状态。此次只部署 MCP 读侧及网关；pipeline 0.16.1、table_spec 1.6.0、mapping/scope 2.0.0 不变。构建侧等价精简经过本地回归，但本轮不切换生产构建运行树、不重启 Dagster、不执行生产 SQL，也不触发电商、FX 或行业构建。

## 发行与宿主验证边界

公共发行只包含白名单插件文件，不包含内部服务器、数据构建、测试、生产操作材料或内部 Git 历史。公开包的发行门禁包括实际清单、版本、相对依赖、文档链接、语法、敏感信息与原生插件验证；正式发行后另读回远端分支、标签、Release 和实际归档。

本地原生兼容回归使用 Claude Code 2.1.299 和 Codex CLI 0.159.2、隔离配置及合成令牌。它证明客户端合同和协议行为，不证明正式用户的安全存储或运行中桌面会话已连接。正式安装与实际连接分别验证，不能以“安装成功”代替取数成功，也不能以新 CLI 进程成功代替旧桌面进程热重载。

WorkBuddy 桌面实机、仅支持 OAuth 的网页连接器以及季报 Workflow 均不在本轮验收范围。MCP OAuth 的停止开发不影响独立的飞书云文档同步能力。

0.3.4 的数据切源、独立源侧验收、金额库外复算和真实季报只属于[当时的验收](ACCEPTANCE-0.3.4.md)，未在本轮重做，也不将其重算为 0.3.5 的新增通过数。
