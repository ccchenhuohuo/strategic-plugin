## 报告阅读与校验

执行摘要在前，正文保留市场结论、结构变化、必要表图和具体局限。通用口径、来源、证据到图表的索引和生成记录进入附录。
没有移除业务表格、证据账本或数字来源检查；缺失不补零，相关的归档、检疫、不可比及数据时效仍需如实表达。

真实数据沿用当前治理代次，服务仍披露上游陈旧；报告说明这一限制。57 张计划图中，55 张可用，一张布局门禁拒绝，一张没有可比品牌坐标。未通过的图不进入报告，表格仍保留。

本机当前 26Q2 报告及所引用的 55 张图已与运行材料逐字节核对，收录索引指向本次完成的飞书文档与附表；旧本机稿保留在季度目录的历史记录中。旧云文档和发布中间稿分别标记为存档与验收中间稿，正式稿保持默认标题。

机械检查证明正文数字来自受治理响应及本次材料，并不证明供应商原始数据完整正确，也不能替代语义审阅。

## 可靠性和支持范围

回归覆盖缓存损坏后的重取、JSON-RPC 响应归属、最终改稿核查、图表引用与复用、冻结连接/输出配置、发布记录 EIO、已知远端资源保留、不确定写入停止以及本地正文/图表归档保护。
独立对抗复查只接触代码、Skill 和合成材料，不接触令牌或真实报告；发布结论以确认缺陷及修正后的验证为准。

同一运行目录由一个控制者管理，不承诺并发发布。飞书写入结果不确定时停止，由人工核对，不能直接重放或跳过。
已收录报告或图表被人工修改时停止自动覆盖；原稿和恢复记录保留。当前数据水位、上游时效和可用字段由受治理服务决定，升级客户端不会刷新数据。

三端安装与配置见[安装指南](INSTALL.md)，组件分工见[架构说明](ARCHITECTURE.md)，具体修订见[更新记录](../CHANGELOG.md)。
