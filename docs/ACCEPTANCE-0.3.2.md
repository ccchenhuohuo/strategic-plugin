## 异常恢复和独立复查

- 取数中断后按原窗口、配置、代次和身份续跑，已成功业务证据复用，账本身份唯一。
- 端点、连接来源、凭据或绑定身份变化，在复用证据前拒绝；缺失身份不降级为旧未绑定运行。
- 当前偏好改变不影响本次冻结输出；完整原身份和冻结收据可在失去网络或令牌时离线收录。
- 无来源数字、直接修改正文或输入版本变化被机械门禁拒绝，旧通过和旧云端同步状态不归给新稿。
- 索引、归档和正文替换的 EIO、结果丢失及中断可恢复；不确定远端写入不自动重放。
- 钩子偏好同路径导入不覆盖源文件；绑定发布只使用冻结 CLI。
- 旧身份升级支持各提交点 EIO；完整摘要一次创建并保留为不可变出处，首次竞争及迟到 old/pending 写入后仍可单执行者恢复和离线收录。

稳定代码整包 436/436、恢复专项 102/102，均 0 失败、0 跳过。方法论生成同步和格式检查通过；官方 Codex 独立对抗复查给出 approve，最后 20 项独立内存探针通过。独立真实文件探针验证了修复前复现与修复后拒绝/恢复，不以开发者自报测试替代验收。

本地摘要用于材料一致性检查，不是抵御同用户全面改写所有记录的签名信任根。同一运行目录由一名执行者取数和写作，不承诺多个 prepare 共同写同一账本。
